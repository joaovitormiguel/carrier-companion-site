# Carrier Companion — website

Marketing site for Carrier Companion, a transportation management system built for fleets by 3PL Systems.

Static site: vanilla HTML, CSS and JS. No build step.

- `index.html` — homepage (hero, what goes away, product overview, a day from above, built for fleets, twenty years, making the switch, CTA, FAQ)
- `product.html`, `built-for-fleets.html`, `switch.html`, `about.html`, `demo.html`
- `css/site.css`, `js/site.js`
- `assets/img` — photography and Model World placeholders (brand-generated stills)
- `assets/ui` — product UI exports from the Figma file

Run locally: `python3 -m http.server 8080` and open http://localhost:8080

Built by hand at Champion Digital Media.
